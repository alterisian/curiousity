═══════════════════════════════════════════════════════════════
WHAT WE BUILT
═══════════════════════════════════════════════════════════════

A local-first Curiosity Memory System that:
  - Ingests raw text
  - Extracts entities + fact triples via LLM
  - Stages extractions in memory (no premature DB writes)
  - Consolidates staged data via a second LLM pass (deduplication)
  - Stores canonical knowledge in SQLite
  - Generates curiosity questions about gaps/contradictions
  - Decays memory notes over time, pruning low-confidence ones

Development methodology: Test-First Driven Development (TFDD)
  - All 66 tests written before any implementation
  - Each test failed with NotImplementedError before being made to pass
  - One stub implemented at a time
  - Full suite run after each implementation to catch regressions

IMPLEMENTATION NOTES
═══════════════════════════════════════════════════════════════

call_llm (curiosity/pipeline.py):
  - Uses urllib.request (stdlib only, no requests package needed)
  - Model: mistral-small-latest
  - Requires MISTRAL_API_KEY env var, raises ValueError if missing
  - Uses response_format: json_object to ensure parseable output
  - Raises ValueError on HTTP errors or invalid JSON

apply_decay (curiosity/db.py):
  - Only touches memory_notes — entities and facts are permanent
  - Multiplies both confidence AND decay columns by decay_factor
  - Prunes rows where confidence * decay <= prune_threshold
  - Returns count of deleted rows

DB constraints added beyond the original spec:
  - NOT NULL on required columns
  - CHECK(confidence >= 0.0 AND confidence <= 1.0) on all confidence columns
  - CHECK(status IN ('pending','active','resolved','dropped')) on curiosity_queue
  - FOREIGN KEY enforcement (PRAGMA foreign_keys = ON in fresh_db())
